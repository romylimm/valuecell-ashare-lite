# Upstream workflows

The original ValueCell workflows are preserved here as reference, outside the active
`.github/workflows` directory. They build and test the full desktop, frontend and trading
distribution. This derivative currently runs the focused A-share Lite checks instead.

These files came from https://github.com/ValueCell-ai/valuecell and retain their original
license. Move individual workflows back only when the corresponding upstream features
are needed and their build/release configuration has been reviewed for this repository.
